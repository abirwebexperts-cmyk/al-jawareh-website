# Al Jawareh Auto Spare Parts — website

A fast, premium, SEO-heavy static site for **jawarehautoparts.ae**. Pure HTML + modern CSS + a little vanilla JS, generated by one Python script into `dist/`. No WordPress, no database, no build tools to install. Deploys to Namecheap cPanel by pushing to GitHub.

Same approach as the Al Rahal site: edit content in `data.py`, run `build.py`, commit, deploy.

---

## What's in here

```
build.py            The generator. Turns data.py into the whole site.
data.py             ALL the content — business info, brands, parts, locations, FAQs, blog posts.
assets/             Source CSS, JS and images (copied into dist/ as-is).
  css/style.css     The design system.
  js/main.js        Menus, the WhatsApp enquiry drawer, small interactions.
  images/           Where your real photos and logos go (see IMAGE-GUIDE.md).
dist/               The built site. THIS is what gets published. Rebuilt every run.
.cpanel.yml         Tells cPanel to copy dist/ into public_html on deploy.
IMAGE-GUIDE.md      Every image the site wants, with exact filename and size.
```

The site builds **122 pages**: home, 9 brand pages, 9 part-category pages, 81 brand×category pages (e.g. *Range Rover Brakes in Sharjah*), 8 location pages, a blog with 6 guides, plus about / contact / FAQ / request-a-part, a 404 page, `sitemap.xml` and `robots.txt`.

## Build it

You need Python 3.8+ (no packages required; install **Pillow** only if you want the script to regenerate the favicon and social-share image).

```bash
python3 build.py
```

That wipes and rebuilds `dist/`. It prints a summary of what it made. Open `dist/index.html` in a browser to preview.

> Optional: `pip install Pillow` lets the script generate `favicon.ico`, `apple-touch-icon.png`, `logo.png` and `og-default.jpg`. Without it, a vector `favicon.svg` is still shipped and everything else works — you'd just add those few images yourself later.

## Edit the content

Everything lives in **`data.py`** — you rarely touch `build.py`.

- **Business details** (phone, WhatsApp, address, hours, email, social links): the `SITE` dictionary at the top.
- **Brands**: the `BRANDS` list. Each has a name, blurb, popular parts, models and a note.
- **Part categories**: the `CATEGORIES` list.
- **Locations**: the `LOCATIONS` list.
- **FAQs**: the `FAQS` list.
- **Blog posts**: the `POSTS` list (title, excerpt, and the body as simple blocks).

Change the text, save, run `python3 build.py` again, commit, deploy. Done.

**WhatsApp number** is set in two places for safety — `SITE["whatsapp"]` in `data.py` and `WA_NUMBER` at the top of `assets/js/main.js`. If the number ever changes, update both.

## Deploy to Namecheap (GitHub → cPanel)

This is the same flow you use for Al Rahal.

### One-time setup

1. **Push this whole folder to a GitHub repo** (public is fine). Include `dist/` — that's what gets published.
2. **Edit `.cpanel.yml`** and replace `CPANEL_USERNAME` with your real cPanel username. So the line reads e.g. `export DEPLOYPATH=/home/aljawa5/public_html/`. Commit that change.
3. In **cPanel → Git™ Version Control → Create**:
   - Clone URL: your repo's HTTPS URL (or SSH if you've added a key).
   - Repository Path: something like `/home/CPANEL_USERNAME/repositories/jawareh`.
   - Branch: `main`.

### Every time you update the site

```bash
python3 build.py           # rebuild dist/
git add -A
git commit -m "Update content"
git push
```

Then in **cPanel → Git Version Control → Manage → Pull or Deploy**:
- **Update from Remote** (pulls your latest push), then
- **Deploy HEAD Commit** (runs `.cpanel.yml`, copying `dist/` into `public_html`).

That's it — the live site updates.

> **Want it fully automatic on push?** Add a GitHub *webhook* pointing at cPanel, or a cron that runs the git pull + deploy on a schedule. cPanel doesn't pull on its own without one of those. The manual two clicks above are the reliable default.

### First-deploy checklist
- `.cpanel.yml` has your real username.
- In cPanel, the domain's document root is `public_html` (default).
- After the first deploy, open `https://www.jawarehautoparts.ae` — the `.htaccess` forces HTTPS + `www`.
- Submit `https://www.jawarehautoparts.ae/sitemap.xml` in Google Search Console.

## Notes

- **Images degrade gracefully.** Until you add real photos, the site shows clean branded placeholders — nothing looks broken. See `IMAGE-GUIDE.md`.
- **No manufacturer logos are shipped.** Brand names are text. Each brand page has a logo slot where you can drop an official logo file if you're licensed to use it.
- **The `.htaccess`** (generated into `dist/`) handles HTTPS + www redirect, gzip, caching, security headers and the 404 page. To change it, edit the `build_htaccess()` function in `build.py`, not the file in `dist/`.
- **HTML is never cached** by the rules, so content changes go live the moment you deploy; CSS/JS/images are cached hard for speed.
